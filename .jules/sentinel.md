## 2026-03-18 - Unpinned GitHub Action Dependency
 **Vulnerability:** Unpinned GitHub Action Dependency
 **Learning:** Using mutable tags (like @v0.7.0) for GitHub Actions allows a potential attacker to compromise the repository if the tag is modified or overwritten.
 **Prevention:** Always pin GitHub Actions to an immutable commit SHA to guarantee the specific code version executed and prevent supply chain attacks.

## 2026-03-20 - Exception details leaked to client
**Vulnerability:** The `/api/publish` endpoint in `infrastructure/app.py` caught arbitrary exceptions and returned `str(e)` directly in the JSON response payload.
**Learning:** Returning raw exception strings to clients poses a significant information exposure risk, as exceptions generated by underlying libraries or services can inadvertently leak system structures, configuration details, or internal logic.
**Prevention:** Always implement a boundary where internal exceptions are logged securely on the server via `logger.error()`, while the client receives a generic, sanitized HTTP 500 error message.
