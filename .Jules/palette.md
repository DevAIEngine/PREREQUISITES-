## 2024-11-09 - Accessible Focus States for Complex Interactive Elements
**Learning:** In React applications with large interactive surfaces (like "Bento Box" cards or massive studio selection buttons) that use inline `style` objects, managing interaction states (hover, focus) via inline event handlers (like `onMouseOver`, `onFocus`) creates accessibility and UX conflicts. For example, `onMouseOut` incorrectly reverts styles when an element maintains keyboard focus. Furthermore, standard inline styles make it difficult to add critical accessibility features like `focus-visible` styling without complex state management.
**Action:** Always extract hover and focus states to CSS classes (using pseudo-classes `:hover` and `:focus-visible`) instead of using inline React event handlers. If the element uses static inline styles, ensure the new CSS classes use `!important` to properly override the inline properties. This guarantees robust mouse and keyboard accessibility for complex elements.
