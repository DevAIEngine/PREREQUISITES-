## 2024-05-18 - [Screen Reader Interpretation of Decorative Emojis]
**Learning:** Decorative emojis like 🎥, 📞, and ☎️ are read aloud literally by screen readers (e.g., "movie camera"), which severely clutters the UI navigation experience for users dependent on screen readers. Attempting to override the emoji's visible representation using `aria-label`s on their parent wrapper causes WCAG 2.5.3 (Label in Name) violations because the visible text (the emoji) no longer matches the programmatic label.
**Action:** When incorporating decorative emojis alongside text, explicitly hide the emojis from the accessibility tree by wrapping them in `<span aria-hidden="true">`. This prevents screen readers from announcing them while retaining the visual aesthetic, ensuring compliance and a seamless auditory experience.
