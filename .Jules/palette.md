## 2026-11-07 - Refactoring JS Interactions to CSS Pseudo-classes
**Learning:** When refactoring inline JavaScript interaction states (e.g., `onMouseOver`) to CSS pseudo-classes on elements that use React inline `style={{...}}` attributes, you must apply the `!important` flag to the new CSS properties to successfully override the static inline styles. Avoid using inline JavaScript event handlers (like `onMouseOver` and `onFocus`) for visual interaction states, as they cause state conflicts (e.g., `onMouseOut` incorrectly reverting styles when an element maintains keyboard focus). Use CSS pseudo-classes (`:hover`, `:focus-visible`) instead to ensure accessibility and consistent behavior.
**Action:** Always prefer CSS pseudo-classes for simple hover/focus effects instead of JS handlers. When modifying legacy code that uses inline styles, ensure `!important` is used in the CSS to override the inline defaults.
